Pick MP4s from desktop. Then upload those same files to the GitHub videos/ folder or SharePoint EchoVideos. The case will link to videos/your-file.mp4.

Example: Line 1 Text = Large circumferential pericardial effusion + Line 1 Media = photo with arrow. Line 2 Text = Right atrial systolic collapse + Line 2 Media = clip link. Leave media empty for text-only lines.
